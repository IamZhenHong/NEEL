# Self-knowledge and identity experiments (queue v3, 2026-10-15)

Seven experiments from the owner's 2026-10-15 list (self-knowledge and identity thread). Each folder has a frozen
design card (`DESIGN.md`, tag `<id>-design`), then the agent's README (implementation, pilot, freeze), REPORT.md and
results. The J-lens items are in `jlens/e2_realism`, `jlens/e3_hallucination`; the CoT items in `cot/`.
Build-and-run rules for all ten: `AGENT_BRIEF.md`.

| id | folder | question |
|---|---|---|
| s1 | `s1_persistence/` | Which planted component (role, task, constraints, past actions) fades first as context grows and across compaction? |
| s2 | `s2_role_wins/` | With several identities in context, which does the model act as, and name? |
| s3 | `s3_saydo_causes/` | Say/do gap: channel training, confabulation (use vs describe), or decision-time pressure? |
| s4 | `s4_accumulation/` | After N small harmful actions, does refusal rise or fall? |
| s5 | `s5_seen_unbiased/` | Does steering a "being watched for fairness" direction move favouritism but not stated values? |
| s6 | `s6_reflective_identity/` | Do induced undesirable personas endorse themselves and resist correction? |
| s7 | `s7_selfmodel_lag/` | During fine-tuning, does self-description change before, with, or after behaviour? |
