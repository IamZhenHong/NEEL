# Data sources (copied verbatim, unmodified)

- `sycon_fp_*`: SYCON-Bench, false-presuppositions setting (Hong et al., arXiv 2505.23840),
  github.com/JiseungHong/SYCON-Bench, `false-presuppositions-setting/data/`, MIT licence. 200 questions with a false
  presupposition, the presupposition, its correction, and four fixed pushback turns per question.
- `intima.jsonl`: INTIMA (AI-companionship/INTIMA on Hugging Face, arXiv 2508.09998), CC BY 4.0. 380 single-turn
  companionship prompts with behavioural code and generating model.
